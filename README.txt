# Shradhay Portfolio Update

## Files
- `index.html` — full portfolio page
- `style.css` — responsive dark theme and zoom intro styles
- `script.js` — intro animation, mobile navigation, reveal effects, active navigation

## Run locally
Keep all three files in the same folder and open `index.html` in a browser. For local development, you can use VS Code Live Server.

## Publish to GitHub Pages
Replace the existing portfolio site's `index.html`, `style.css`, and add `script.js` to the same folder/branch that GitHub Pages publishes from. Keep the filenames exactly as referenced in the HTML.
